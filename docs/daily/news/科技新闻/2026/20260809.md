# 科技新闻 2026\-08\-09
> Intel为Linux 7.3合并窗口提交补丁，增强集群感知调度，改善P核与E/LPE核混合架构的负载均衡。 Linux内核7.2-rc7硬件监控子系统修复大量由AI机器人发现的关键或高危缺陷，凸显AI辅助代码审计对内核安全的影响。 Linux 7.2-rc7发布，含AI驱动补丁修复信息泄露、越界访问等安全漏洞，并为游戏控制器增加XPad驱动支持。
