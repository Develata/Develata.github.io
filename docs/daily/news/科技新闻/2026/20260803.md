# 科技新闻 2026\-08\-03
> Linux 7.3合并窗口将纳入高通MSM DRM显示驱动更新，新增对Adreno 704与Adreno 722 GPU的支持，扩展内核图形硬件兼容性。 Linux 7.3将开始合入Intel Starfire航天级SoC（Panther Lake衍生）的初始补丁，为太空环境应用奠定内核基础。
