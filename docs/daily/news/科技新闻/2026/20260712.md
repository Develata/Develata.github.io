# 科技新闻 2026\-07\-12
> LLVM 上游合并 x86 LFI（轻量级故障隔离）目标，实现进程内高效原生码沙箱，继 AArch64 后扩展至 x86 架构。 Mesa项目默认启用Rusticl对Arm Mali Panfrost驱动支持，由Arm工程师贡献，提升Mali GPU的OpenCL可用性。
