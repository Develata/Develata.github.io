# Quicker 使用指南

## 1. 什么是 Quicker

[Quicker 官网](https://getquicker.net/)

Quicker 是北京立迩合讯科技有限公司开发的 Windows 效率工具。它把“启动程序、打开文件、发送文本、模拟按键、运行脚本、处理选中内容”等操作封装为可点击或可触发的**动作**，再按当前软件自动切换动作页。与单纯的启动器相比，Quicker 更接近一个可视化 Windows 工具箱和轻量自动化平台。

它的核心用途有三类：

* **缩短入口**：用鼠标中键呼出面板，一步打开常用软件、文件夹、网址或系统设置。
* **减少键鼠切换**：把快捷键、文本模板、截图 OCR、翻译、搜索等操作放到鼠标附近。
* **自动化重复流程**：用组合动作连接多个步骤，通过变量、条件和循环完成跨软件操作。

Quicker 是闭源商业软件，提供免费版和专业版。基础面板与动作足以完成入门；多动作页、轮盘菜单、全局动作快捷键、扩展热键、动作历史版本等高级能力可能需要专业版，具体以[官方功能说明](https://getquicker.net/kc/manual/doc/pro-version)为准。

## 2. 安装与更新

### 2.1 使用 Scoop 安装（推荐）

Quicker 当前不在 Scoop 官方 `extras` bucket 中，可使用面向中文软件的第三方 bucket `Scoopforge/Extras-CN`。该 manifest 下载 `fast_x64` / `fast_x86`，对应 Quicker **快速通道**，并非官方稳定通道；希望由 Scoop 统一管理且愿意跟进较新版本时再采用。重视稳定性的工作机应改用下一节的官方稳定通道。先确认已经安装 [Scoop](./Scoop.md)，再在**同一 Windows 用户的管理员 PowerShell**中执行：

```powershell
scoop bucket add extras-cn https://github.com/Scoopforge/Extras-CN
scoop update
scoop search quicker
scoop install extras-cn/quicker
```

Quicker 需要注册 `quicker://` URL protocol，因此该 manifest 会请求管理员权限。第三方 bucket 不是 Quicker 官方发行渠道；安装前可检查 manifest、下载地址和哈希：

```powershell
scoop cat extras-cn/quicker
scoop info extras-cn/quicker
```

验证安装：

```powershell
scoop list quicker
scoop prefix quicker
```

随后从开始菜单启动 **Quicker**。日后更新：

```powershell
scoop update
scoop update quicker
```

### 2.2 使用官方安装包

如果不希望信任第三方 bucket，可从[官方下载页](https://getquicker.net/Download)下载安装包。官方提供常规通道和较新的快速通道；工作机优先选择稳定通道，遇到兼容性问题再按官方说明切换版本。

> 不建议同时保留 Scoop 版与官方安装版。两套程序可能共用 `%LOCALAPPDATA%\Quicker` 数据，却由不同更新机制管理，容易造成路径和版本混乱。

## 3. 先理解四个核心概念

| 概念 | 含义 | 例子 |
| :--- | :--- | :--- |
| **动作** | 一次可执行操作 | 打开 Obsidian、粘贴邮箱、运行 PowerShell 脚本 |
| **动作页** | 一组动作按钮 | 浏览器页、Excel 页、全局工具页 |
| **场景 / 上下文** | 当前正在使用的软件 | 在 Excel 中呼出面板时加载 Excel 动作页 |
| **触发方式** | 如何执行动作 | 面板点击、全局快捷键、轮盘菜单、文本指令、鼠标手势 |

面板通常分为两部分：

* **全局面板区**：始终显示，适合放截图、搜索、剪贴板、常用目录等通用动作。
* **上下文面板区**：随当前程序切换，适合放某个软件独有的操作。

这个模型比堆满一个“万能面板”更重要：高频通用动作放全局区，软件专属动作放上下文区，低频动作放到后续页面或搜索中。

## 4. 第一次配置

### 4.1 呼出面板

Quicker 默认可用鼠标中键呼出面板；也可以在设置中改为侧键、快捷键、短按/长按或其他方式。第一次使用建议暂时保留中键：移动距离短，也不占用常见键盘快捷键。

基本流程：

1. 启动 Quicker，确认托盘区存在图标。
2. 在桌面按鼠标中键，呼出面板。
3. 点击已有动作，确认能够执行。
4. 切换到浏览器、编辑器或 Office，再次呼出面板，观察下半部分是否随场景变化。

如果中键与浏览器自动滚动、CAD 或游戏操作冲突，可更换触发键，或把对应程序加入黑名单。

### 4.2 创建第一个基础动作

在空白按钮上单击或右键，选择动作类型并填写参数。最值得先建立的动作是：

* **运行程序**：选择 `.exe`，例如编辑器或终端。
* **打开文件夹**：指向下载、项目、截图或临时目录。
* **打开网址**：保存高频网页入口。
* **模拟按键**：把难记的组合键映射为可视按钮。
* **发送文本**：保存不敏感的模板文本。
* **执行脚本**：调用 `.ps1`、`.cmd`、`.bat` 等脚本。

不要在“发送文本”或动作参数中保存密码、API Key、恢复码等秘密；同步、分享、导出或截图都可能扩大泄露面。

### 4.3 组织动作页

推荐按使用频率分层：

1. 第一页只放每天都会用的动作。
2. 同类操作集中排列，例如“搜索 / 翻译 / OCR”放在一起。
3. 软件专属操作放到对应场景，不占全局区。
4. 一周都没用过的动作移到后页或删除。
5. 动作名称使用动词开头，如“打开项目”“复制路径”“压缩为 ZIP”，避免只有图标而不知其义。

## 5. 动作库：先借力，再定制

[Quicker 动作库](https://getquicker.net/Share)提供大量社区动作。安装流程：

1. 在动作库找到动作，先阅读说明、权限需求、更新记录和讨论。
2. 复制动作分享网址。
3. 在 Quicker 空白按钮上右键，选择“粘贴分享的动作”。
4. 第一次运行时检查配置项，再授予所需权限。

动作有更新时会出现角标，可从右键菜单的“来源动作”更新或重新安装；也可在设置中批量更新。

### 5.1 动作库的安全边界

社区动作可能执行脚本、访问网络、读取剪贴板、修改文件或调用外部程序。安装前至少检查：

* 是否来自可信作者，是否有足够的说明和讨论；
* 是否请求与用途无关的管理员权限；
* 是否包含看不懂的 PowerShell、批处理或下载执行逻辑；
* 文件删除、批量改名、注册表修改是否提供预览或确认；
* 网络请求会把哪些文本、图片或文件发送到第三方。

原则是：**能看懂再运行，权限按需给；先在非重要数据上试，再进入日常工作流。**

## 6. 从基础动作到组合动作

组合动作把多个模块按顺序连接，模块之间通过变量传递数据。一个实用动作通常包含四层：

1. **输入**：选中文本、剪贴板、文件、用户输入。
2. **处理**：替换、匹配、计算、调用程序或 Web API。
3. **控制流**：条件分支、循环、异常处理。
4. **输出**：发送文本、写入文件、弹窗提示、打开网页。

### 6.1 示例：搜索选中文本

逻辑可以设计为：

```text
读取选中文本
  ↓ 若为空，则读取剪贴板
URL Encode
  ↓
拼接搜索引擎网址
  ↓
打开网址
```

关键点不是步骤多，而是处理空输入、特殊字符和失败情况。好的组合动作应在输入缺失时明确提示，而不是静默执行错误操作。

### 6.2 示例：批量归档文件

```text
选择多个文件
  ↓
逐个读取扩展名
  ↓
按扩展名创建目标目录
  ↓
移动文件
  ↓
汇总成功数与失败数
```

涉及文件移动或删除时，先复制到测试目录验证；正式使用前增加冲突策略、失败提示和日志。不要把“无确认永久删除”作为默认路径。

### 6.3 设计技巧

* 把重复步骤提取为子程序，避免复制粘贴后各自漂移。
* 变量名表达含义，例如 `selectedText`、`targetDir`，不要只用 `a`、`tmp1`。
* 对外部命令检查退出状态，对网络请求设置超时和失败分支。
* 长流程在关键节点显示进度，结束时给出结果摘要。
* 先实现稳定的正常路径，再增加循环、并发或自动触发。

## 7. 触发方式怎么选

| 方式 | 适合场景 | 注意事项 |
| :--- | :--- | :--- |
| 面板点击 | 可视化、高频但不想记快捷键 | 最适合入门 |
| 全局快捷键 | 极高频、结果确定的动作 | 避免与软件快捷键冲突 |
| 文本指令 | 编辑时插入模板或触发处理 | 避免过短指令导致误触 |
| 轮盘菜单 | 鼠标主导、动作数量较少 | 依赖肌肉记忆，先固定布局 |
| 鼠标手势 | 浏览器、文件管理等连续操作 | 游戏、绘图软件中建议禁用 |
| 悬浮动作 | 一段时间内反复使用同一动作 | 用完及时收回，避免遮挡 |
| 事件触发 | 登录、窗口切换、定时自动化 | 高风险动作必须防止重复触发 |

建议顺序是：**面板 → 少量全局快捷键 → 文本指令 / 轮盘 → 自动触发**。不要刚安装就同时开启所有输入钩子，否则很难判断冲突来自哪里。

## 8. 同步、备份与多设备

登录后，Quicker 可以同步用户设置、应用设置和动作页，但不会同步所有运行数据。官方说明中，动作历史版本、动作状态数据、动作生成的文件和下载组件等不属于常规同步范围。

本地数据默认位于：

```text
%LOCALAPPDATA%\Quicker\
```

其中常见内容包括：

```text
data\quicker.db       面板、动作等主要数据
imagecache\           图标缓存
logs\quicker.log      日志
states\               动作状态数据
```

### 8.1 多台电脑的正确用法

Quicker 不是实时协同编辑系统。两台电脑同时登录并修改配置，可能发生后同步的一端覆盖前一端。稳妥做法：

1. 指定一台电脑作为主要编辑端。
2. 修改完成后立即手动同步。
3. 在另一台电脑编辑前先手动拉取最新数据。
4. 多机程序路径不同时，优先使用环境变量或备用路径，不要硬编码用户名目录。

### 8.2 备份建议

* 定期备份整个 `%LOCALAPPDATA%\Quicker` 目录。
* 重要组合动作单独导出，并用清楚的文件名标记用途和日期。
* 专业版可使用动作历史版本，但它不能替代完整数据备份。
* 重装系统前确认动作状态、额外组件和“我的文档\Quicker”中的数据是否需要另行保存。

## 9. 实用配置建议

### 9.1 一套克制的全局页

推荐只保留：

* 文件 / 程序搜索
* 截图与 OCR
* 翻译与网页搜索
* 打开下载目录、项目目录、终端
* 剪贴板处理
* 常用但不敏感的文本模板

### 9.2 给软件建立上下文页

* **浏览器**：复制标题与网址、无痕窗口、网页翻译、保存为 PDF。
* **文件管理器**：复制完整路径、计算哈希、批量改名、压缩与解压。
* **编辑器**：格式化、运行测试、打开项目终端、搜索选中文本。
* **Office**：粘贴纯文本、常用格式、导出 PDF、表格清洗流程。

动作应围绕“当前软件中高频且稳定的操作”建立，而不是把所有可能功能都塞进来。

## 10. 故障排查

| 现象 | 检查与处理 |
| :--- | :--- |
| 中键无法呼出面板 | 确认 Quicker 正在运行；检查触发键设置、黑名单和全屏禁用；排查鼠标驱动或其他手势软件冲突 |
| 面板在某个软件中误触 | 将该程序加入黑名单，或只在全屏时禁用 |
| 动作无法启动程序 | 检查程序路径；多机环境优先使用环境变量或备用路径 |
| 动作更新后行为改变 | 查看来源动作的更新记录；必要时切换版本或恢复备份 |
| 两台电脑配置互相覆盖 | 停止双端同时编辑，确定最新端后手动同步到服务器，再让另一端拉取 |
| 软件异常或动作报错 | 从 Quicker 菜单打开应用数据目录，检查 `logs\quicker.log`；反馈前先移除账号、路径和隐私数据 |
| Scoop 更新后快捷方式异常 | 执行 `scoop update quicker`，确认 `scoop prefix quicker` 指向当前版本；避免同时安装官方版 |
