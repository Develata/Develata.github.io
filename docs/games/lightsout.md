# 💡 关灯游戏 (Lights Out)

**规则：**
1. 点击一个方块，它和它上下左右的邻居状态都会反转（亮变灭，灭变亮）。
2. **目标**：将所有灯全部熄灭。

**数学原理：**
这是一个经典的线性代数问题。在有限域 $\mathbb{F}_2$ 上求解线性方程组 $Ax=b$。

每一个自由练习初始局面是否可解？

我们生成的局面是**从全灭状态逆向推导**出来的，因此根据线性变换的可逆性，**必定有解**。
