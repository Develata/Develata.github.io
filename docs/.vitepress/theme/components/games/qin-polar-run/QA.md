## 成本与 CI 核验

最终实现样本：111 场景节点、6 个上传几何体、0 张纹理；桌面约 96–100 次绘制调用，
手机竖屏样本 95 次。竖屏 DPR 实测封顶 1.25。上述数量在重开和路线推进时保持有界。
优化前为 976 节点、密集画面约 173 次调用；障碍/路面实例化去除了该结构性开销。
不把桌面触摸模拟称为真实 Android GPU 性能验收，也未声称某个测得帧率。

每帧 576 字节帧缓冲，一次粗粒度 WASM 调用，约 1.1KiB 双向复制。
热路径没有新建 Three.js 对象、数组或材质；生成绑定仍有小型临时切片分配，未声称零分配。

CI 变更自审确认：只在精确输出缓存缺失时安装 Rust、测试和构建；命中时直接做 Node/VitePress 构建。
新闻路径不进入 Rust 缓存键；没有重复 Rust 工作流；原 Pages 权限/并发/环境/部署 action 保留。
本地已成功从源码生成包并用生产站点消费；尚未提交远端，未声称 GitHub Actions 实际发生过缓存命中。
