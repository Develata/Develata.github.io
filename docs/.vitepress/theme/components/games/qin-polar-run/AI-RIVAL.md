# 实时 AI 残影：实现与验收

日期：2026-10-18。基线提交 `3382c7934a3d11f50a7ae626caf372aa0fc5369c`，独立分支 `codex-qin-polar-ai-ghost`。
首次实现验收时工作区基线干净，尚未提交、推送、合并或部署；本文件记录发布前的实现与本地验证。没有修改锁文件、依赖、凭据或权限。

## 实现边界

- 实时反馈控制器每个 120Hz 固定步读取自己前方的障碍，再输出 LEFT/RIGHT 动作位。直接复用 `RunnerCore` 和 `Player::tick`，不直接写位置、不跳过碰撞、不加速换道。
- AI 的目标是零碰撞。它采用地面安全路线，不追逐恢复排的金币，不使用跳跃、俯身或冲刺。双方具有相同动作能力与速度函数；这是策略选择，非额外速度或动作限制。没有最高分最优性承诺。
- 玩家冲刺、免疫、撞击减速、跳跃和俯身保持原规则。AI 也走同一碰撞规则，异常路线真的会受撞、减速并在第二次有效受撞时停止。单独记录原始碰撞，包括冲刺破障接触，不把保护期间的接触当成零碰撞。
- 青色半透明秦始皇与北极熊使用同一模型与真实坐标。图形层没有任何反向影响核心的接口。关闭只影响显示，暂停/后台隐藏则冻结双方。
- HUD 直接使用累计距离差，单位米；SCORE 仍包括金币，不用作距离。视野外用方向和距离提示，不把角色夹到屏幕边缘伪造位置。AI 接触过障碍时显示计数，停止时显示“AI 已停止”。

## 同一个世界，独立消耗状态

`World` 定义固定种子、固定 epoch 和绝对路段序列。`Cursor` 克隆同一初始生成状态，严格按绝对路段编号前进；生成参数是绝对原点和固定 epoch，**不再传入请求时刻或某一方的相对进度**。
两游标生成同编号路段时具有相同障碍、金币车道和原点，这是共同的确定性世界流，并非保留旧的时间依赖生成后只给两个核心相同 seed。

每方只持有八个窗口及自己的 collected/resolved/smashed 状态。领先者回收窗口不会改变落后者的游标或状态；无须存储两人之间的整个距离区间。
玩家破障不删除 AI 的障碍，AI 拾取也不删除玩家金币。两人不参与彼此的碰撞检测。

路段原点与累计距离为 f64，相对渲染 z 每步重新相减转为 f32。距离差先在 f64 中相减再传给 HUD，避免分别转换大距离后的消差误差。

生成器的模式、随机数序列和安全校验仍复用原实现。为使地形不随输入改变，速度上界采用从世界起点出发的保守时间界；部分后期障碍间距会比旧实现更宽。旧版本 seed 地形不保证兼容，玩家物理和动作冷却保持不变。

## 安全策略依据与假设

1. 每个有效障碍排至少保留一条站立安全道。模式无法通过生成器校验时，原有规则会产生空排；AI 本身不会删除障碍或改造不可行局面。
2. 有效障碍排之间的距离至少为 `2×WINDOW + arrival_speed_bound×decision_headway`。当前 WINDOW=1.15m，decision_headway=1s。
3. 控制器锁定最近的有效排，直到其后缘完全经过碰撞窗。随后选择下一排距离当前目标车道最近的空道，最多连续换两道。量化后每道 20 步，两道 1/3 秒；再加离开窗口判断最多一个固定步，仍小于生成器保留的 1 秒。
4. 空排不触发改道，因此不会因追恢复排金币而进入下一障碍的错误车道。AI 不冲刺，普通速度上界足够。最低前进速度 7.8m/s 和单调速度函数保证绝对距离给出的时间界保守；暂停不增加任何时间。
5. 八段前视覆盖至少约 330m；最高速度保护为 120m/s，每步前进不超过 1m，小于完整 2.3m 碰撞窗。控制器能看到下一有效排，并且不会跨步跳过整个窗口。

这些论据依赖当前生成模式、窗口、动作时长、速度函数、固定步长和有界前视。未来更改上述任一项应重验。有限测试不是对无限运行或任意外部障碍的证明。全阻塞排故障注入已验证：AI 会发生碰撞且可结束，不隐藏失败。没有发现当前生成器无可行路线的样本。

## 性能与限制

- WASM 由 23,579 增至 27,346 bytes（+3,767）；JS 绑定仍 7,361 bytes。没有新增依赖、纹理、网络服务、账号、排行榜或运行时 LLM。
- ABI 从 144 增至 160 个 f32（576→640 bytes）；仍每浏览器帧一次 advance，双向复制约 1.25KiB。
- 物理多一个固定大小的核心；AI 每步扫描 16 排，线性常数成本，无搜索树或热路径堆分配。两人进度差不会增加内存容量。
- 首版直接绘制复制模型约 153 次调用；自查后改为按几何体/材质实例合批。生产样本残影开启 105–108 次、关闭 90–93 次，增量约 15 次；146 个场景节点、7 个已上传几何体、0 纹理。角色几何体共享，只有材质克隆及一个圆环。
- 没有测量真实 Android/iOS GPU、耗电或长时间实体设备温升。SwiftShader 仅验证渲染正确性，不代表手机帧率。
- f64 累计数值仍有有限精度，累计距离输出为 f32；极端长会话 HUD 绝对距离精度会下降，差值先相减的接口缓解但不声称无限精度。
- 首次本地验收尚未覆盖线上部署、远端缓存、服务端配置或账户验证；发布后的证据应以对应 PR、CI 和线上验收记录为准。环境共享设置未暴露给 shell，本轮没有更改可见性。
